# PathfinderCheck

Автономные проверки алгоритма поиска пути (`Assets/scripts/PathFinding/GridPathfinder.cs`).

## Зачем отдельный проект

`GridPathfinder` не зависит от UnityEngine: обвязку с картой держит `Pathfinding.cs`.
Благодаря этому алгоритм проверяется обычным консольным прогоном — без Unity,
лицензии и запуска редактора.

Лежит вне `Assets/`, поэтому Unity эти файлы не импортирует и не компилирует.
Тесты на NUnit внутри `Assets/` появятся, когда в проекте будет свой `asmdef`
(иначе тестовый код попадёт в `Assembly-CSharp` и потребует NUnit в рантайме).

## Запуск

```sh
cd Tools/PathfinderCheck
dotnet run
```

Проверяется **реальный исходник проекта** (файл подключён ссылкой в `.csproj`),
а не его копия. Успешный прогон печатает `Итог: 21 passed, 0 failed`.

## Что покрыто

| # | Проверка |
|---|---|
| 1 | Прямой коридор: путь найден, длина равна манхэттенскому расстоянию |
| 2 | Ступенька высотой 1: путь поднимается на неё и спускается (длина +2) |
| 3 | Непроходимая стена: возвращается `null` |
| 4 | Старт совпадает с целью: пустой путь, а не `null` |
| 5 | Цель внутри стены: `null` |
| 6 | Бюджет раскрытых узлов: при крошечном бюджете поиск завершается без зависания |
| 7 | Повторные вызовы: пути не делят общий буфер и не портят друг друга |
| 8 | Сетка 200×200: путь оптимален и находится мгновенно |
| 9 | Разрыв в полу: колонка без опоры непроходима |
| 10 | 20 запросов подряд: алгоритм не накапливает состояние |

## Правила проходимости

Проверки повторяют игровую логику `Pathfinding.IsWalkable`: клетка проходима,
если она пустая и под ней есть опора на 1 или 2 клетки ниже. Следствие, которое
полезно помнить при правке карты: **одна отсутствующая клетка пола делает всю
колонку непроходимой** (проверка №9).
